# Resumo de Estudos para Certificações AWS

Este repositório é dedicado a compartilhar o material de estudos que utilizei para as certificações **AWS Cloud Practitioner** e **AWS AI Practitioner**. O objetivo é oferecer um guia de referência para outras pessoas que estão se preparando para essas certificações, reunindo informações importantes e conceitos essenciais abordados nos exames.

## Conteúdo

O repositório inclui os seguintes arquivos:
- `aws-cloud_practitioner.md`: Resumo dos principais tópicos abordados na certificação `AWS Cloud Practitioner`, incluindo fundamentos de nuvem, conceitos de segurança, arquitetura e os principais serviços da AWS.
- `aws-ai-practitioner.md`: Material de estudo para a certificação `AWS AI Practitioner`, com foco em serviços de machine learning e inteligência artificial na AWS.

Boa sorte nos seus estudos e na sua jornada de certificação AWS!
